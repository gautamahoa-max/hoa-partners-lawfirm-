## 🏛 Giới Thiệu Dự Án

Trang web chính thức của **Công ty Luật TNHH Hòa & Cộng sự** (HOA & PARTNERS LAW FIRM), được xây dựng theo tiêu chuẩn thẩm mỹ hiện đại **Clean White Minimalist**, tối ưu hóa trải nghiệm di động (**Mobile-First**) và tích hợp các công cụ tương tác thực chiến dành cho khách hàng doanh nghiệp và cá nhân.

---

## ✨ Các Tính Năng Nổi Bật

1. **Giao Diện Đẳng Cấp & Chuẩn Mực Pháp Lý**:
   - Tông màu hoàng gia: Deep Midnight Navy (`#0A2647`) kết hợp Vàng Kim (`#C59B27`) tượng trưng cho Cán cân công lý và trí tuệ pháp luật.
   - Bố cục thông thoáng, tinh gọn, không rườm rà, loại bỏ triệt để các khối viền lồng nhau.

2. **Bảng Tính Án Phí Tòa Án (Nghị quyết 326/2016/UBTVQH14)**:
   - Tự động tính toán mức **Án phí sơ thẩm** và **Tiền tạm ứng án phí (50%)** chuẩn xác theo giá trị tranh chấp (Kinh doanh thương mại & Dân sự/Đất đai).
   - Hiệu ứng số nhảy mượt mà (Animated Counter) khi kéo thanh trượt.

3. **Bộ Đánh Giá Sức Khỏe Pháp Lý (Interactive Legal Health Check)**:
   - Bài khảo sát 4 câu hỏi trắc nghiệm nhanh phát hiện lỗ hổng hợp đồng, bản quyền và quản trị nội bộ trước khi trở thành tranh chấp.

4. **Phễu Chuyển Đổi Liền Mạch (Event-Driven Pre-fill)**:
   - Khi khách hàng tính toán án phí hoặc chọn gói dịch vụ, hệ thống tự động điền sẵn thông tin vào Form liên hệ và cuộn mượt xuống phía dưới.

5. **Pop-up Modal Chi Tiết Dịch Vụ**:
   - Trực quan hóa quy trình 4 bước, căn cứ pháp lý và sản phẩm bàn giao cho từng lĩnh vực hành nghề cốt lõi: Tranh tụng Tòa án & VIAC, Pháp chế Doanh nghiệp, Hợp đồng, M&A, Đất đai, Sở hữu trí tuệ.

6. **Băng Chuyền Đối Tác & Hiệp Hội (Infinite Marquee)**:
   - Liên đoàn Luật sư Việt Nam (VBF), Trung tâm Trọng tài Quốc tế (VIAC), Đoàn Luật sư Hà Nội & TP.HCM, VCCI, VNBA...

7. **Tiện Ích Kết Nối Nhanh Trên Di Động (Floating Action Widget)**:
   - Gọi Hotline 24/7 khẩn cấp, Chat Zalo trực tiếp với Luật sư và Đặt lịch hẹn chỉ với 1 chạm.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Trên Thiết Bị Khác

### Yêu Cầu Hệ Thống:
- Node.js version 18 trở lên
- Git

### Các Bước Thực Hiện:

```bash
# 1. Clone repository về máy
git clone https://github.com/gautamahoa-max/hoa-partners-lawfirm-.git

# 2. Di chuyển vào thư mục dự án
cd hoa-partners-lawfirm-

# 3. Cài đặt các gói phụ thuộc
npm install

# 4. Khởi chạy môi trường phát triển (Development)
npm run dev

# 5. Đóng gói bản chạy thực tế (Production Build)
npm run build
```
